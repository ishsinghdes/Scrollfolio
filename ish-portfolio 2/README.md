# Portfolio & Works

Ish Singh’s responsive portfolio. Static HTML, CSS and JavaScript; no install, build or server-side dependency is required.

Keep this folder’s asset hierarchy intact. It contains the original project media plus 30 final screenshots and four silent H.264 recordings supplied on 12 November 2026. All project galleries use their actual media, with no empty tiles. Videos autoplay muted, loop and play inline; reduced-motion preferences pause motion.

The homepage library contains the introduction and 17 projects. Grey sleeves decelerate into place, then reveal their artwork. Clicking a side sleeve centres it; clicking the centred sleeve opens its moodboard. Mouse, trackpad, touch and keyboard are supported.

Project stickers can be dragged during the visit and reset when the project is reopened. Double-click or double-tap one to preview and download its transparent PNG. Native sharing appears where supported. The compact contact CTA opens the visitor’s email app addressed to ishnishansingh@gmail.com.

The project Return Mac leads back to the library. Focused media closes to the original canvas location. The tab and sharing title remain Portfolio & Works.

For the existing deployment, preserve the folder name `ish-portfolio 2`. Its original hosting root remains this folder. For GitHub Pages, publish this folder’s contents as the selected static-site root. A local preview may be run using any static web server.
