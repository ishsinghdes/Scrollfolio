# Upload the final portfolio

1. Extract `Portfolio-GitHub-Final.zip` on your computer.
2. In your existing portfolio repository, replace the matching `ish-portfolio 2` folder with the complete folder from the ZIP.
3. Keep all nested `assets` folders exactly as supplied. Do not flatten the folders or upload only the HTML file.
4. Commit and push using GitHub Desktop, or upload the extracted files through GitHub in folder-sized batches. Do not upload the ZIP itself as the website.
5. Keep the existing deployment root set to `ish-portfolio 2`. No build command is required; output is the same folder.

Your local `macfolio` repository has also been updated, so GitHub Desktop can commit and push those changes directly if you prefer.

This is the complete website package. No original MOV files, temporary previews, local analysis files or `.git` directory are included. New recordings are silent web-compatible MP4s; the largest website file is below 9 MB. Every directory contains at most 30 immediate items.

The package adds 30 screenshots and four recordings across Arena, PITO, Aurya, Car Analytics, Crisis Management, IQ Test, Data & App Organiser, Siemens MR/VR, Wolfie and Audio Visualizer / 444 Records. The additional Data & App Organiser and Siemens screenshots were assigned by their visible content. All supplied project media is included; no supplied asset gaps remain.
